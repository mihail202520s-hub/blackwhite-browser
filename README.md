# BlackWhite Browser

Минималистичный браузер на движке Chromium с чёрно-белой темой и скруглёнными углами.

## Установка

1. Перейдите в раздел [Releases](../../releases)
2. Скачайте файл **BlackWhiteSetup.exe** из раздела **Assets**
3. Запустите установщик

**Важно:** не скачивайте архивы "Source code (zip)" и "Source code (tar.gz)" — это исходный код, а не установщик.
